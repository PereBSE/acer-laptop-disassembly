# Acer Laptop Disassembly and Reassembly Lab
 
## Objetivo
 
Este laboratorio se realizó como práctica de desmontaje y montaje de hardware portátil dentro de mi proceso de formación en soporte TI y microinformática.
 
El objetivo principal fue familiarizarme con la estructura interna de un portátil, identificar sus componentes y realizar el proceso completo de desmontaje y posterior montaje verificando su correcto funcionamiento.
 
## Equipo utilizado
 
- Portátil Acer Aspire 5610 series Model nº: BL50
- Sistema operativo Windows XP
- Equipo reutilizado como laboratorio de aprendizaje práctico
 
## Tareas realizadas
 
- Apertura completa del equipo
- Identificación de componentes internos
- Inspección visual del hardware
- Proceso de desmontaje ordenado
- Cambio de pasta térmica en la CPU
- Montaje completo del equipo
- Verificación funcional tras el ensamblaje
